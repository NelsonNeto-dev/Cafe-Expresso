# ☕ Café Expresso

## 📌 Descrição
Projeto desenvolvido para a disciplina Engenharia de Software Avançada, com o objetivo de criar um sistema para gerenciamento de um café.

---

## 🎯 Objetivo
Desenvolver um sistema em Java para controle de pedidos e produtos de uma cafeteria.

---

## 👨‍💻 Integrantes
- Nelson Neto

---

## ⚙️ Funcionalidades
- Cadastro de produtos
- Criação de pedidos
- Cálculo de total

---

## 🧪 Testes
Serão utilizados testes unitários com JUnit.
